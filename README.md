# TypeScript + Express + MongoDB

Этот проект представляет собой серверное приложение на Node.js с использованием Express и MongoDB. Он включает в себя функциональность для регистрации и авторизации пользователей с различными ролями.

## Требования

- [Node.js](https://nodejs.org/) (требуемая минимальная версия 16 или выше)
- Современный веб-браузер

## Запуск приложения

1. Установка зависимостей

```bash
yarn install
```

2. Установить Docker
3. Запустить контейнер с образом mongo

```bash
docker run -d -p 27017:27017 --name mongo mongo:latest
```

4. Узнать настройки для подключения
   Примонтировать терминал к контейнеру

```bash
docker exec -it mongo bash
```

Запустить команду `mongosh` внутри контейнера

```bash
mongosh
```

Найти ссылку для подключения типа `mongodb://127.0.0.1:27017/?directConnection=true&serverSelectionTimeoutMS=2000&appName=mongosh+2.3.4`

5. yarn run dev

## Использование

1. Добавьте файл .env и пропишите

```bash
MONGO_URI= путь_к_монго
JWT_SECRET= пароль
```
